# Original Emerald Hall of Fame

Emerald now uses the pinned original Hall controller for the six-member
fly-in, individual cries and information, team dimming, confetti, player
portrait and congratulations. Its own text, bands, stripes, seventeen
confetti frames, twenty user frames, message box and egg picture/palette
are extracted from the verified Emerald cartridge. The existing host owns
induction, party IDs, ribbons, statistics and the completion callback.

Three additional reference files are retained byte-for-byte from
`fb7b0366efcb85e703e9e6d5a8a24d01456a109b`, separately hashed in provenance.
Their original GPLv3/additional terms remain intact. The native controller
and graphics renderer were already retained for RS. The Emerald adapter
uses Emerald's constants, font, frame geometry, trainer pictures and music.
No generated cartridge resources are published.

`emerald-native-hall-v1` rejects the previous approximate ceremony cache.
Readiness requires all 27 movie-independent art/frame/metadata resources,
both trainer portraits, every original label and native confetti dimensions.
Draw-time save/RNG values remain unchanged. The egg image is privately owned
and released with the screen; other sprite paths retain the host's Hall hook.

The initial six-member native fixture passes a fresh full import at
`905defcad9b6b05c7652d6bc94b7515a0eb83ebe`: actual GameClear special,
all six Hall members, confetti, female portrait, ordinary final input,
complete 57-page/71-slide Emerald credits and resumed script. Fifteen
final-renderer captures pass. The subsequent small-team fixture exposed a
missing host egg-image field; the final adapter extracts Emerald's original
egg directly rather than relying on that field.

These are prepared presentation fixtures. Emerald's atomic League save,
title reset and ordinary full-story coverage remain separate work. The
shared native RS adapter retains its existing save/title/CONTINUE behavior.
