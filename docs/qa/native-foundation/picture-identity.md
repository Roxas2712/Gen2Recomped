The native GBA graphics namespace has Unown A at201 and its other27 pictures at413..439, independently of the412-row name table. The fixed supported edition profiles all declare that name-table size. The personality selector reads the low two bits of each byte and normalizes signed uint32 representations. It uses portable integer arithmetic without requiring a bit library during module loading. Reference: [pret/pokefirered species constants](https://github.com/pret/pokefirered/blob/ce6406d8c2eaf46d543c8a2606de0c3cb1951982/include/constants/species.h) and [LoadSpecialPokePic](https://github.com/pret/pokefirered/blob/ce6406d8c2eaf46d543c8a2606de0c3cb1951982/src/decompress.c).
