# Native action presentation rows

`battle.anim_seq.begin` decorates the actual presentation rows created by one
verified native action callback. It receives detached event arrays with immutable
identities. The native used-message and move-animation constructors provide their
provenance; message language and content are never used to identify an event.
Other rows remain opaque native events. The same native queue executes HP, items,
experience, UI and gameplay callbacks.

A decorator may omit only this admission's qualified move-animation and
move-used message events. Retained events keep their native order. Foreign,
duplicate, reordered or missing mandatory events are rejected. Native row/cohort
changes, covered screens and retired phases invalidate permission. The first
base request owns the once-only choice; filtering commits only when the whole
decorator returns successfully. Errors cannot replay the native action or partly
commit presentation filtering. A row carrying another native protocol keeps its
mandatory identity. Returned event views retain no controller after retirement.

Only native action-plan rows open this production boundary. Default and no-op
behavior use the original native queue and clock. No additional interpreter,
executable event stream or combat calculation is created. Used-message IDs name
the actual native `_ItemUseText001` producer. Source requires no translated text
comparison.

This supplies the begin/filter subset, not the complete animation-driver API.
Resolver, pre-dispatch action phase and typed HP/RNG continuation remain open;
Action Card stays gated. Other sequence methods and arbitrary detached event
playback are not advertised. No unchanged-mod contact-cue or performance
acceptance is derived from synthetic native tests.

The owned native fixture compares complete HP/PP/every-RNG/frame traces for all
five GBA editions with the module absent, default, and no-op decorated. Targeted
cases exercise actual producers, protected rows, phase/cohort loss, callback
attribution, malformed/foreign requests and errors before/after the base call.
Player data and private mod sources are not changed.
