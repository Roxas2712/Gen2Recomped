The source region-map spellings observe the real constructor-admitted native
screen. They neither open another screen nor move/select its cursor. Returned
views retire with their native screen, inner RS task, edition, dataset, save,
loader or Game facade. Cursor records and destination coordinates are detached;
a nested modal prevents input-ready status. Native visit/target and heal-location
owners decide the destination. RS special gender, League-position and Battle
Tower handling stays in its existing native resolver, also used by the picker.

The generic Hoenn picker has no fade task. Its actual input-ready phase projects
to protocol state12, while non-ready phases project to0. Its type query covers
only current native selectable fly targets (category2) and returns0 elsewhere;
it does not supply a complete route/city/landmark classification. The actual RS
controller retains its own phase, movement counter and native type classification.
FR/LG captures the player's real section before its constructor's early return,
fixing its otherwise unset initial page/player marker. Cross-page forecasts are
refused. Neither these observations nor source warming mutate visits or flags.

Native flight still resolves one spot and runs its existing departure body once.
Source fly wrappers receive its section, current party view and detached exact
destination. Repeated base calls cannot repeat the departure, and a caught native
failure cannot be retried. Standalone requests go through existing WorldActions
badge/move/visited/map/input admission. Other generations bypass this source seam.
The field Game query resolves the current native facade without retaining a world.
