# Native GSC PP source API and ownership

Prepared on the independently selected-qualified current-upstream composition
from PR400 (`dfe0e44a`, original main `8d5b4387`). This adds the actual native
Gen2 PP arithmetic prerequisite and the source `ppUpsOf`, `maxPpOf`,
`partyMoves`, `restoreAllPp` and `repairMoves` signatures. Native heal and
real save validation share the same actual move-slot operations. Existing
native item, held-item, battle/wide HUD, script and link calculations use that
maximum too, including the seven-point GSC bonus cap, legacy saved maxima
and SKETCH's PP-Up refusal. Other generations retain their existing formula.

The arithmetic groundwork is the scoped production portion of existing
commit `03c0534e`. Its separate UI selector and unavailable older menu-result
producers are not copied or presented as implemented by this change. This
host's inherited RNG constructor, the remaining source Mon API, standalone
battle/turn APIs, native selector UI parity and complete visual/release
acceptance remain separate open requirements.

Qualification of this combined older host is pending. The new source-API
fixture exercises the real older SDK, native healing, actual save validation,
sparse boxes and all breeding slots. A second test exercises actual ETHER,
MYSTERYBERRY, PP UP and link reconstruction. The newer fork's 6642 source-API
checks and six native regression groups do not qualify these older bytes.
No mod, Gen1 reference or player installation is edited.
